# Outbreak Protocol

A lightweight browser pandemic strategy game. No frameworks, no backend, no paid anything. **Entirely vibe coded using Claude free model**, inspired by the pandemic-sim genre that *Plague Inc.* made popular. I built it to test what vibe coding and reverse-engineering a game's mechanics can really do with AI, using the **free version of Claude**. Total working time was about 4 hours, spread over five days (Oct 16 to 20, 2026).

### ▶ Play it: https://sugarblast.github.io/Game-demo/
