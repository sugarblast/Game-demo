# Outbreak Protocol

A lightweight browser-based pandemic strategy game inspired by the pandemic simulation genre. Built with Claude's free model using plain HTML, CSS, JavaScript, Canvas 2D, and Web Audio.

## ▶ Click to Play:
https://sugarblast.github.io/Game-demo/

## Features

* Strategy and evolution: Develop 22 upgrades across transmission, symptoms, and abilities.

* Global simulation: Spread a pathogen across 45 world regions while adapting to different climates.

* Progression: Unlock 26 trophies and earn ratings based on your performance.

* Browser-based: No backend, installation, or paid services required. Progress is saved locally.

## Development

I used AI to generate the game's code, tests, sound effects, and satirical content. My role focused on game design decisions, play-testing, identifying bugs, refining gameplay balance, and deploying the project.

The game includes automated tests for simulation balance, progression, browser interactions, and performance.
